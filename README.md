# Google Cloud 入門資格 学習アプリ

Google Cloud の入門資格2件の統合学習アプリです。

- **Cloud Digital Leader（CDL）**：現行試験ガイド（2026-08-12改定、6セクション版）準拠。問題300問・用語147語・レッスン12本
- **Generative AI Leader**：公式試験ガイド（4分野）準拠。問題240問・用語110語・レッスン10本

機能：モード切替、レッスン（図解付き）、セクション別問題演習、模試（90分・55問、配分比例抽選）、用語集、フラッシュカード、学習進捗の保存（localStorage）。

問題は全てオリジナル作成です。Google の公式合格点は非公開のため、模試の合否目安（正答率70%）は学習上の目安です。
