# Google Cloud 資格・教養 学習アプリ

Google Cloud 関連の4モード統合学習アプリです。

- **Cloud Digital Leader（CDL）**：現行試験ガイド（2026-08-12改定、6セクション版）準拠。問題300問・用語147語・レッスン12本、模試90分・55問
- **Generative AI Leader**：公式試験ガイド（4分野）準拠。問題240問・用語110語・レッスン10本、模試90分・55問
- **NotebookLM・Studio**：NotebookLM の使い方と Studio 活用。問題150問・用語85語・レッスン8本、総合テスト30問
- **Google Cloud**：資格範囲に縛られない一般教養。問題150問・用語84語・レッスン8本、総合テスト30問

機能：レッスン（図解付き）、セクション別問題演習（全文検索・弱点絞り込み・選択肢シャッフル）、模試（見直しフラグ・中断再開）、間違えた問題の復習＋間隔反復（SRS）、ブックマーク、分析（初見／再挑戦正答率）、用語集、フラッシュカード（3段階自己評価）、設定（ダークモード、起動時モード、記録のエクスポート／インポート／初期化）、学習進捗の保存（localStorage）。

問題は全てオリジナル作成です。Google の公式合格点は非公開のため、資格モードの模試の70%は学習上の目安です。
